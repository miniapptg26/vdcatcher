# ВЕЙП ДЕД · ЖИЖА 🍶

8-бит ретро-мини-игра в духе «лови яйца»: Вейп-дед в бордовой кепке, с чёрной бородой и вейпом, ловит баночки жидкости.
Статический Telegram Mini App: HTML + CSS + JS, без сервера.

## Файлы
- `index.html` — разметка, HUD, экраны старта/конца (включая титулы)
- `styles.css` — 8-бит стиль: плоские цвета, твёрдые тени, шрифт Press Start 2P
- `game.js` — логика и пиксельная отрисовка: баночки, дед, PERFECT, ПАР-БОМБА, титулы, звуки, рекорд
- `tests.js` — юнит-тесты чистых функций GameCore (запуск: `node tests.js`)

## Управление
- Тач/мышь: веди пальцем или курсором — дед плавно следует за целью (просто коснись нужного места)
- Клавиатура: ← → (или A/D)
- Enter / Space — старт и рестарт

## Механики
- Жидкости — пиксельные баночки 5 вкусов: 🍓 🍉 🍋 🫐 🌿
- ✨ Золотая жижа — +50 очков
- 🚬 Окурки — минус жизнь, сброс комбо (со 2 уровня)
- Бонусы: ❤️ +1 жизнь · ⏳ замедление · 🧲 магнит · ⚡ турбо · 💨 ПАР-БОМБА
- Комбо до x3: каждые 5 пойманных подряд +0.5 к множителю
- 💨 **ПАР-БОМБА**: взрывает все окурки на экране, +10 очков за каждый
- 🎯 **PERFECT**: поймай банку точно в центре деда — +25% очков и надпись PERFECT!
- 👑 **Титулы-ранги** (по рекорду): НОВИЧОК → ЛАКОМКА → ЛОВЕЦ БАНОК → ГРОЗА ОКУРКОВ → МАСТЕР ПАРА → ЛЕГЕНДА ЖИЖИ
- Уровни: каждые 250 очков ускоряют падение и частоту спавна
- Рекорд хранится в localStorage

## Дизайн
- 8-бит палитра: тёмно-синий фон, жёлтый/белый акцент, плоские заливки, твёрдые тени
- Персонаж из пикселей: **бордовая кепка с козырьком**, **чёрная борода с прядями**, усы, кафтан, сапоги, вейп с мигающим кончиком и паром
- Всплывающие надписи (+очки, PERFECT!, ВЗРЫВ!) в стиле ретро-шрифта

## Деплой на GitHub Pages
1. Создай репозиторий (например `vapeded-juice`) и загрузи `index.html`, `styles.css`, `game.js`, `README.md` в ветку `main`.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save.**
3. Через ~1 минуту сайт будет на `https://<твой-логин>.github.io/<repo>/`.
4. **BotFather:**
   - новый бот: `/newapp` → название → описание → фото → URL мини-аппа → короткое имя (например `vapededjuice`);
   - существующий бот: `/mybots` → бот → **Bot Settings → Menu Button** → указать URL мини-аппа.
5. Открой игру из меню бота. Интерфейс растянется (`Telegram.WebApp.expand`), тема тёмная.
