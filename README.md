# ВЕЙП ДЕД · ЖИЖА 🍶

8-бит ретро-мини-игра в духе «лови яйца»: Вейп-дед с бородой и вейпом ловит баночки жидкости.
Статический Telegram Mini App: HTML + CSS + JS, без сервера.

## Файлы
- `index.html` — разметка, HUD, экраны старта/конца
- `styles.css` — 8-бит стиль: плоские цвета, твёрдые тени, шрифт Press Start 2P, без неона
- `game.js` — вся логика и отрисовка: баночки, пиксельный дед, комбо, бонусы, звуки Web Audio, рекорд
- `tests.js` — юнит-тесты чистых функций GameCore (запуск: `node tests.js`)

## Управление
- Тач/мышь: веди пальцем или курсором — дед плавно следует за целью (просто коснись нужного места)
- Клавиатура: ← → (или A/D)
- Enter / Space — старт и рестарт

## Механики
- Жидкости — пиксельные баночки 5 вкусов: 🍓 🍉 🍋 🫐 🌿 (цвет корпуса = вкусу, эмодзи на этикетке)
- ✨ Золотая жижа — +50 очков
- 🚬 Окурки — минус жизнь, сброс комбо (появляются со 2 уровня)
- Бонусы: ❤️ +1 жизнь · ⏳ замедление · 🧲 магнит · ⚡ турбо
- Комбо до x3: каждые 5 пойманных подряд +0.5 к множителю; пропуск или окурок сбрасывают серию
- Уровни: каждые 250 очков ускоряют падение и частоту спавна
- Рекорд хранится в localStorage

## Дизайн
- 8-бит палитра: тёмно-синий фон, жёлтый/белый акцент, плоские заливки, твёрдые тени 4px
- Персонаж собран из пикселей: ушанка, седая борода, усы, кафтан, вейп с мигающим кончиком
- Банки падают с лёгким покачиванием, у окурка тлеющий кончик
- Сканлайны и неоновые свечения убраны

## Деплой на GitHub Pages
1. Создай репозиторий (например `vapeded-juice`) и загрузи `index.html`, `styles.css`, `game.js`, `README.md` в ветку `main`.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save.**
3. Через ~1 минуту сайт будет на `https://<твой-логин>.github.io/<repo>/` — проверь в браузере.
4. **BotFather:**
   - новый бот: `/newapp` → название → описание → фото → URL мини-аппа → короткое имя (например `vapededjuice`);
   - существующий бот: `/mybots` → бот → **Bot Settings → Menu Button** → указать URL мини-аппа.
5. Открой игру из меню бота. Интерфейс сам растянется (`Telegram.WebApp.expand`), тема тёмная.
