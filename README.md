# ВЕЙП ДЕД · Башня

Telegram Mini App — 3D-игра-клон Stake/Stack: строй башню из коробок жидкости для вейпа. Чистый статик (HTML + CSS + JS), без бэкенда и сборки.

## Как играть
Нажми «Играть» — игра начнётся после первого тапа (важно для мобильных WebView и звука). Тап по сцене — сброс коробки. Перекрытая часть становится новым слоем башни, свешивающаяся отрезается и падает. Не перекрыл — башня рассыпалась. Скорость растёт с высотой, каждые 6 слоёв меняется ось движения, каждые 3 слоя — новый вкус.

## Скины
В меню доступны 4 скина коробок: Неон (по умолчанию), Классика (картон), Хайп (кислотные градиенты), Металл (хром). Выбор сохраняется в localStorage.

## Запуск локально
```
python3 -m http.server 8090
```
Открой http://localhost:8090

## Деплой на GitHub Pages
1. Создай репозиторий и загрузи 4 файла: `index.html`, `styles.css`, `game.js`, `README.md`.
2. Settings → Pages → Build and deployment: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт на `https://<username>.github.io/<repo>/` — проверь, что открывается по HTTPS.

## Подключение к Telegram
1. В BotFather выбери бота для мини-приложения (или создай нового).
2. Отправь `/newapp` → выбери бота → имя приложения (например «ВЕЙП ДЕД Башня») → вставь URL с GitHub Pages (HTTPS, без порта) → короткое имя (например `tower`).
3. Получи ссылку вида `https://t.me/<bot>/tower` — открой в Telegram и играй.

## Особенности
- Старт строго по кнопке: корректно работает в Telegram WebView, на iOS/Android (AudioContext создаётся после жеста).
- Рекорд, звук и скин хранятся в localStorage.
- Звук синтезируется Web Audio API — внешних файлов нет.
- Оптимизация: лимит обломков (22), пауза цикла в фоне, dt-кламп, will-change, крупные тач-цели (44px+).
